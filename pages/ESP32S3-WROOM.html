ESP32 Complete Pin Reference

A comprehensive reference for the original Espressif ESP32 architecture, including GPIO, ADC, DAC, touch sensing, RTC GPIO, UART, SPI, I2C, PWM, boot strapping, JTAG, flash-connected pins and common Arduino usage.

ESP32 WROOM-32D 34 GPIO 3 UART 2 I²C SPI ADC DAC

Reference Scope

Important: ESP32 refers to a family of chips and modules. This page primarily documents the original ESP32 silicon and the ESP32-WROOM-32 / WROOM-32D class modules. Other members of the ESP32 family, such as ESP32-S2, ESP32-S3, ESP32-C3, ESP32-C6 and ESP32-H2, have different GPIO counts and peripheral mappings and should have their own dedicated encyclopedia entries.

GPIO Safety Classification

SAFE

Generally Flexible

GPIO18, GPIO19, GPIO21, GPIO22, GPIO23, GPIO25, GPIO26, GPIO27, GPIO32 and GPIO33 are commonly useful for general projects, subject to peripheral configuration.

INPUT-ONLY

Analog / Input Focus

GPIO32–39 provide ADC1 channels. GPIO34–39 are input-only and therefore cannot drive LEDs, relays or other outputs.

CAUTION

Boot / Strapping

GPIO0, GPIO2, GPIO5, GPIO12 and GPIO15 participate in ESP32 startup configuration. External circuits connected to these pins must not unintentionally force an invalid boot configuration.

RESERVED

Reserved for Flash

GPIO6–GPIO11 are connected to the ESP32's internal SPI flash interface on WROOM-class modules and should not be treated as normal external GPIO.

PWM / LEDC

The ESP32 LEDC peripheral provides hardware PWM functionality. PWM can be used for LEDs, motors, servos and other control applications.

  • LED brightness control
  • Motor speed control
  • Servo-style pulse generation
  • Tone generation
  • Hardware-timed periodic waveforms

PWM-capable signals can generally be routed through the GPIO matrix rather than requiring one permanently dedicated PWM pin.

I²C

I²C is a two-wire synchronous bus commonly used for sensors, OLED displays, RTC modules, ADCs, GPIO expanders and EEPROM.

SDA GPIO21
SCL GPIO22

GPIO21 and GPIO22 are the common Arduino-ESP32 defaults, but the ESP32 GPIO matrix allows I²C signals to be assigned to other suitable GPIOs.

SPI

SPI is a synchronous high-speed serial interface commonly used for displays, SD cards, RFID readers, flash memory, sensors and other peripherals.

Signal Common ESP32 GPIO Typical Meaning
SCK GPIO18 Clock
MISO GPIO19 Controller input
MOSI GPIO23 Controller output
CS GPIO5 Chip select

GPIO5 is commonly used as a chip-select line, but because it participates in boot strapping, designs should ensure the connected peripheral does not create an unwanted boot state.

UART

The classic ESP32 contains three UART controllers: UART0, UART1 and UART2.

Boot & Strapping Pins

Strapping pins are sampled during reset/startup to determine configuration parameters. After reset, they can operate as normal GPIOs.

Important Design Rule

Never assume a strapping pin behaves like an ordinary GPIO during the entire power-on sequence. External pull-ups, pull-downs, sensors, displays and other peripherals can influence the startup configuration.

Pin Strapping Role Design Consideration
GPIO0 Boot mode Low during reset can select download mode
GPIO2 Boot mode Startup level matters
GPIO5 Strapping Startup state matters
GPIO12 / MTDI Flash voltage Critical for flash configuration
GPIO15 / MTDO Strapping Startup state matters

Flash-Connected GPIO

Do Not Use GPIO6–GPIO11 as Normal I/O on WROOM

GPIO6 through GPIO11 are associated with the ESP32's SPI0/SPI1 flash interface. On WROOM-class modules these signals are normally consumed by the module's internal flash. 

GPIO6   → Flash
GPIO7   → Flash
GPIO8   → Flash
GPIO9   → Flash
GPIO10  → Flash
GPIO11  → Flash

Treat these pins as reserved when designing around an ESP32-WROOM-32D.

Example — SSD1306 OLED

ESP32 WROOM-32D

GPIO21  ───────── SDA
GPIO22  ───────── SCL
3.3V    ───────── VCC
GND     ───────── GND
  
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define OLED_SDA 21
#define OLED_SCL 22

Adafruit_SSD1306 display(
  128,
  64,
  &Wire,
  -1
);

void setup() {

  Wire.begin(
    OLED_SDA,
    OLED_SCL
  );

  display.begin(
    SSD1306_SWITCHCAPVCC,
    0x3C
  );

  display.clearDisplay();

  display.setTextColor(
    SSD1306_WHITE
  );

  display.setCursor(
    0,
    0
  );

  display.println(
    "ESP32 ONLINE"
  );

  display.display();
}

void loop() {
}

Exact boot configuration also depends on additional strapping configuration and the specific ESP32 implementation. GPIO0 and GPIO2 should therefore be treated as startup-sensitive signals.

ESP32 Engineering Rules

  1. Never use GPIO6–11 as normal WROOM GPIO. They are associated with the module's flash interface.
  2. Remember GPIO34–39 are input-only. They cannot drive outputs.
  3. Prefer ADC1 for analog measurements when Wi-Fi is active.
  4. Treat GPIO0, GPIO2, GPIO5, GPIO12 and GPIO15 as boot-sensitive.
  5. Do not assume Arduino defaults are hardware restrictions. The ESP32 GPIO matrix provides substantial signal routing flexibility.
  6. Identify the exact module. ESP32-WROOM, WROVER and newer ESP32-family devices are not interchangeable pin-for-pin.
  7. Verify the development board separately. Board labels, regulators, USB interfaces and exposed pins vary between manufacturers.
  8. Check the datasheet before production hardware. Development-board conventions are not substitutes for electrical specifications.
